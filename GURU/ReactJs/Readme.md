## 📘 NOTES

  * `document.getElementsByClassName()`
* Modify elements:

  * `innerText`, `innerHTML`, `textContent`
  * `style.property`
* Create elements:

  * `document.createElement()`
  * `appendChild()`, `prepend()`, `remove()`
* Events:

  * `onclick`
  * `addEventListener()`

## 📘 NOTES

* Built-in modules:

  * fs
  * path
  * http
* Create server:

```js

  res.end("Hello World");
});
```
